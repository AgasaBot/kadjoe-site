# Kadjoe — Interior Design & Build

**Live site: https://agasabot.github.io/kadjoe-site/**

A portfolio showcase for **PT Kadjoe Kreasi Indonesia** (Jakarta, est. 2017) — *The Balance of
Subtle Luxe and Unmatched Quality*.

- **111 projects** across Residential · F&B · Retail · Office · Wellness, every photo from
  Kadjoe's own website and Instagram (@kadjoe_id)
- **27 partner design studios** credited and linked on every project, plus Kadjoe's in-house
  design-and-build work — see [Design Partners](https://agasabot.github.io/kadjoe-site/designers.html)
- Static site, no build step: hand-rolled HTML/CSS/JS, WebP imagery, keyboard-accessible
  galleries, JSON-LD, sitemap

|---|---|

| `portfolio.html` | All 111 projects with sector filters |
| `projects/*.html` | 111 detail pages — meta, designer credit, gallery + lightbox |

| `about.html` / `contact.html` | Studio story, services, values, contact |
